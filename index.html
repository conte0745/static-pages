Chrome拡張機能

CHROME EXTENSION

CaptGrab

TypeScript Vite Chrome拡張

画面サイズを固定して、Webページ全体を1枚のPNGにするChrome拡張機能です。

1クリックで保存とコピーまでできます。

  • 画面いっぱいの表示も崩れず、画像の継ぎ目も出ない
  • 撮影サイズや保存先を設定で変更できる
  • アカウント登録なし、画像は外部に送信しない
紹介を見る ↗ ストアで見る ↗ CHROME EXTENSION

EviREST

JavaScript Chrome拡張

HTTP/REST APIの送信・検証と、テストエビデンスの出力ができるChrome拡張機能です。

  • アサーション結果からOK / NGを自動判定
  • エビデンスをHTML・Excelで出力
  • アカウント登録なし、データはブラウザ内だけ
